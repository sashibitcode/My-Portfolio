## 🚀 Local Development Setup

Clone the repository and run locally in under 60 seconds:

```bash
# 1. Clone repository
git clone https://github.com/sashibitcode/My-Portfolio.git

# 2. Navigate to project root
cd My-Portfolio

# 3. Install dependencies
npm install

# 4. Launch local dev server
npm run dev
```

Server will boot up at `http://localhost:3000`.

### 📦 Production Build
```bash
npm run build
```
Generates a minified, production-ready bundle in the `dist/` directory.

## 🌐 Automatic Deployment

This repository includes a preconfigured **GitHub Actions Workflow** (`.github/workflows/deploy.yml`):
- Every push to the `main` branch automatically triggers a build and deploys to **GitHub Pages**.
- **Live URL:** [https://sashibitcode.github.io/My-Portfolio/](https://sashibitcode.github.io/My-Portfolio/)

To enable GitHub Pages in your repo:
1. Go to repository **Settings** ➔ **Pages**.
2. Under **Build and deployment** ➔ **Source**, select **GitHub Actions**.
3. That's it! GitHub Actions handles continuous deployment automatically.
